The launcher is a pipe: version resolution, loader installation, dependency pins, and runtime handoff wired end to end in Rust — so the marketing never has to outrun the mechanics.

See it in action

Short loops cut straight from the real interface — no storyboards, no mockups.

conic · instance library

01 — Instances

Every world, one rail

All your worlds and modpacks live on a single rail — sorted by play time, pinned to favorites, grouped by loader. Pick one and hit Launch; the current instance sits highlighted and the rest stay out of the way.

  • Sort · Search
  • Favorites
  • Group by loader
conic · marketplaces

02 — Packs & mods

The marketplaces, inside the launcher

Browse Modrinth and CurseForge without ever leaving the app. Dependencies are resolved for you, translated summaries stay intact, and installation is one click into the active instance.

  • Modrinth · CurseForge
  • Dependencies auto-resolved
  • One-click install
conic · launch pipeline

03 — Launch

Watch it come alive

Press Launch and the pipeline takes over: version resolved, loader installed, assets verified, game up — honest progress at every step. Java is auto-detected (or downloaded), and memory is tuned with a 32-bit cap so older packs don't choke.

  • Java auto-detect
  • Memory auto-tuned
  • Live stage progress
conic · game data

04 — Game data

Your worlds, tidy

World maps are rendered with their real icons, mods and data packs are one tap away, and screenshots preview right in the app. No digging through .minecraft folders to find anything.

  • Live save icons
  • Mods · data packs
  • Screenshot previews
