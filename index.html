Open-source Minecraft launcher · Rust core · Tauri 2 + Vue 3

Every launch, on a curve.

Conic Launcher is a small, fast, nimble, cross-platform launcher. From installing instances and loaders to resolving mods and inviting friends — the whole pipeline is one app, engineered to stay out of the way.

01/06

The launcher is a pipe: version resolution, loader installation, dependency pins, and runtime handoff wired end to end in Rust — so the marketing never has to outrun the mechanics.

02/06 — System

Capabilities

What the ship actually does — each card maps to a real subsystem with a defined protocol.

A

Multi-instance management

Instances grouped by loader, with sort, search, favorites, per-instance settings, custom backgrounds, playtime, and last-played at a glance.

DB · registry
B

All major loaders

Vanilla, Forge, NeoForge, Fabric, and Quilt with real-time installation progress — pick a version, the resolution pipeline handles the rest.

IP · resolver
C

Mod & pack marketplaces

Built-in Modrinth and CurseForge search — dependencies, translated summaries, and one-click install into the active instance.

HTTPS · REST
D

Conic Nexus networking

Cross-LAN multiplayer without extra tools — room and invite codes, NAT detection, and optimization suggestions baked in.

TCP · NAT
E

Multiple login methods

Microsoft (device code), offline, and Authlib-Injector / Yggdrasil, with 3D skin preview, cape display, and skin upload.

OAuth · Yggdrasil
F

Hassle-free launch

Java auto-scan or download, auto memory with 32-bit cap protection, and a fully visualized launch pipeline for advanced args.

JVM · CLI
G

Saves & game data

Browse world maps, manage data packs and resource packs, and review screenshots — all inside the launcher.

FS · world
H

UI & personalization

Four Catppuccin themes with high-contrast variants, auto light/dark, custom backgrounds, and a built-in spectrum music player.

CSS · theme
I

And more

Auto-updates and version notifications, multi-threaded downloads with mirrors and proxy support, global search and command palette, playtime tracking.

OTA · CLI

03/06 — Layout

Architecture

A split control plane: Vue 3 + Pinia front end over a Rust core, exposed through a thin Tauri IPC boundary.

runtime → wry · x11 · macos-private-api

data → versioned directory · playtime · activity calendar
